# 🌾 Bezlepkový Skener (SK)

Open-source nástroj na identifikáciu bezlepkových potravín dostupných na slovenskom trhu pomocou EAN kódov.

## 🚀 Ciele projektu
- Agregovať dáta z viacerých zdrojov (Open Food Facts, MZ SR, lokálni výrobcovia).
- Poskytnúť rýchle overenie bezpečnosti potraviny pre celiatikov.
- Umožniť komunite dopĺňať chýbajúce slovenské produkty.

## 🛠️ Plánovaný technologický stack
- **Jazyk:** Python (backend/data processing)
- **API:** Open Food Facts JSON API
- **Frontend:** (Zatiaľ v diskusii - React Native / Flutter?)
